# Visual Studio Code — Windows Keyboard Shortcuts & Commands

## General

| Command | Shortcut | Description |
|---|---|---|
| Command Palette | `Ctrl + Shift + P` | Open all available commands |
| Quick Open | `Ctrl + P` | Search and open files |
| Settings | `Ctrl + ,` | Open user/workspace settings |
| Keyboard Shortcuts | `Ctrl + K` `Ctrl + S` | View and customize shortcuts |

---

## Basic Editing

| Command | Shortcut | Description |
|---|---|---|
| Cut line | `Ctrl + X` | Cut entire line (no selection) |
| Copy line | `Ctrl + C` | Copy entire line (no selection) |
| Move line up/down | `Alt + ↑` / `Alt + ↓` | Move current line |
| Copy line up/down | `Shift + Alt + ↑` / `Shift + Alt + ↓` | Duplicate line |
| Insert line below | `Ctrl + Enter` | Insert blank line below |
| Insert line above | `Ctrl + Shift + Enter` | Insert blank line above |
| Delete line | `Ctrl + Shift + K` | Delete entire line |
| Indent / Outdent | `Ctrl + ]` / `Ctrl + [` | Increase/decrease indentation |
| Go to beginning of line | `Home` | Move cursor to start of line |
| Go to end of line | `End` | Move cursor to end of line |
| Go to beginning of file | `Ctrl + Home` | Move cursor to file start |
| Go to end of file | `Ctrl + End` | Move cursor to file end |
| Scroll line up/down | `Ctrl + ↑` / `Ctrl + ↓` | Scroll without moving cursor |
| Fold / Unfold | `Ctrl + Shift + [` / `Ctrl + Shift + ]` | Collapse/expand code block |
| Toggle comment | `Ctrl + /` | Comment/uncomment current line |
| Block comment | `Shift + Alt + A` | Toggle block comment selection |
| Format document | `Shift + Alt + F` | Auto-format entire file |
| Format selection | `Ctrl + K` `Ctrl + F` | Auto-format selected code |

## Multi-Cursor & Selection

| Command | Shortcut | Description |
|---|---|---|
| Select all | `Ctrl + A` | Select entire file |
| Select word | `Ctrl + D` | Select current word (press again for next match) |
| Select all occurrences | `Ctrl + Shift + L` | Select all matching words |
| Add cursor | `Alt + Click` | Add cursor at clicked position |
| Add cursor above/below | `Ctrl + Alt + ↑` / `Ctrl + Alt + ↓` | Add cursor on adjacent line |
| Column selection | `Shift + Alt + Drag` | Select rectangular block |
| Expand selection | `Shift + Alt + →` | Expand selection by syntax scope |
| Shrink selection | `Shift + Alt + ←` | Shrink selection by syntax scope |
| Undo last cursor | `Ctrl + U` | Undo last cursor operation |

## Search & Replace

| Command | Shortcut | Description |
|---|---|---|
| Find | `Ctrl + F` | Search in current file |
| Replace | `Ctrl + H` | Find and replace in current file |
| Find in files | `Ctrl + Shift + F` | Search across entire project |
| Replace in files | `Ctrl + Shift + H` | Find and replace across project |
| Toggle regex | `Alt + R` | Enable/disable regular expression |
| Toggle case-sensitive | `Alt + C` | Enable/disable case matching |
| Toggle whole word | `Alt + W` | Match only whole words |
| Add selection to next find match | `Ctrl + D` | Add next occurrence to selection |
| Go to next/previous match | `F3` / `Shift + F3` | Navigate search results |
