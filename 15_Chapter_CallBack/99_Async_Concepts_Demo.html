⚡ JavaScript Async Concepts

Interactive demos for new Promise(), async/await, Promise.all, Promise.race & more

📦 new Promise() Foundation

A Promise represents a value that may be available now, later, or never. It takes a callback with resolve (success) and reject (failure).

const order = new Promise((resolve, reject) => { setTimeout(() => { const ok = Math.random() > 0.3; ok ? resolve("✅ Pizza is ready!") : reject("❌ Out of stock"); }, 1500); });

⏳ async / await Sugar

async makes a function return a Promise. await pauses execution until the Promise settles — making async code read like synchronous code.

async function makeCoffee() { console.log("☕ Brewing..."); await wait(2000); // pause 2s console.log("✅ Coffee ready!"); return "☕ Enjoy!"; }

🏎️ Promise.all() Parallel

Runs multiple promises in parallel. Resolves when all succeed. If any rejects, the whole thing rejects immediately.

Promise.all([ fetchUsers(), fetchOrders(), fetchProducts() ]) .then(results => { // All 3 complete → results[0], results[1], results[2] }) .catch(err => { // First rejection wins });

🥇 Promise.race() First Wins

Returns as soon as the first promise settles (resolve or reject). Great for timeouts — if a task takes too long, the timeout wins.

Promise.race([ fetchData(), timeout(3000) ]) .then(winner => console.log("First:", winner)) .catch(err => console.error("Timeout!", err));

📋 Promise.allSettled() All Results

Waits for all promises to settle (resolve or reject). Never short-circuits — you get every result, good or bad.

Promise.allSettled([ goodPromise, badPromise ]) .then(results => { results.forEach(r => { // r.status === "fulfilled" | "rejected" }); });

🎯 Promise.any() First Success

Resolves when any promise resolves (first success wins). Ignores rejections unless all reject.

Promise.any([ slowOK(), fastFail(), mediumOK() ]) .then(winner => console.log("First success:", winner)) .catch(err => console.error("All rejected", err));

🛡️ try/catch Error Handling

With async/await, use try/catch/finally to handle errors gracefully — just like synchronous code.

async function safeFetch() { try { const data = await riskyAPI(); console.log("✅ Data:", data); } catch (err) { console.error("❌", err.message); } finally { console.log("🏁 Done"); } }

🚀 Real Dashboard Combined

A realistic e-commerce dashboard using Promise.all to fetch orders, users, and inventory in parallel, with async/await.

async function loadDashboard() { const [orders, users, stock] = await Promise.all([ fetchOrders(), fetchUsers(), fetchStock() ]); renderDashboard({ orders, users, stock }); }
