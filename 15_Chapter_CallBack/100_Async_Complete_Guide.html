📞 Callback Foundation

A callback is a function passed into another function as an argument. Synchronous callbacks run immediately (like Array.map()). Asynchronous callbacks run later (like setTimeout). Nesting too many creates "Callback Hell" 🔥.

// Sync callback — runs immediately [1,2,3].map(n => n * 2); // Async callback — runs later setTimeout(() => { console.log("⏰ 2 seconds later"); }, 2000); // Callback Hell — nested callbacks placeOrder(101, id => { processPayment(id, id => { shipOrder(id, id => { sendConfirmation(id); }); }); });

📦 new Promise() Foundation

A Promise represents a future value. It takes an executor function with resolve (success) and reject (failure). Use .then() for success, .catch() for errors, .finally() for cleanup.

const pizza = new Promise((resolve, reject) => { setTimeout(() => { Math.random() > 0.3 ? resolve("🍕 Pizza ready!") : reject("❌ Out of stock"); }, 1500); }); pizza.then(msg => console.log(msg)) .catch(err => console.error(err)) .finally(() => console.log("🏁 Done"));

⏳ async / await Sugar

async makes a function return a Promise. await pauses execution until the Promise settles — making async code read like synchronous code. Can only use await inside async functions.

async function makeCoffee() { console.log("☕ Brewing..."); await delay(2000); // pause 2 seconds console.log("✅ Coffee ready!"); return "☕ Enjoy!"; }

🏎️ Promise.all() Parallel

Runs multiple promises in parallel. Resolves when all succeed. If any rejects, the whole thing rejects immediately (fail-fast). Returns results in the same order as the input array.

const [users, orders, stock] = await Promise.all([ fetchUsers(), // 2.0s fetchOrders(), // 1.5s fetchStock() // 2.5s ]); // Total time: ~2.5s (not 6s!)

🥇 Promise.race() First Wins

Returns as soon as the first promise settles (resolve or reject). Great for timeouts — if a task takes too long, the timeout wins. The rest are abandoned.

Promise.race([ fetchData(), // might be slow timeout(3000) // rejects after 3s ]).then(data => console.log(data)) .catch(err => console.error("⏰ Timed out!"));

📋 Promise.allSettled() All Results

Waits for all promises to settle (resolve or reject). Never short-circuits — you get every result with { status, value/reason }. Perfect when you need all outcomes regardless of failures.

const results = await Promise.allSettled([ goodTask(), // ✅ resolves badTask(), // ❌ rejects slowTask() // ✅ resolves later ]); results.forEach(r => { // r.status === "fulfilled" | "rejected" });

🎯 Promise.any() First Success

Resolves when any promise resolves (first success wins). Ignores rejections unless all reject (then throws AggregateError). Like race() but only counts successes.

Promise.any([ failFast(), // ❌ ignored succeedSlow(), // ✅ wins! failSlow() // ❌ ignored ]).then(winner => console.log("🏆", winner)) .catch(err => console.error("All rejected!"));

🛡️ try / catch / finally Error Handling

With async/await, use try/catch/finally to handle errors gracefully — just like synchronous code. finally always runs whether there was an error or not (cleanup, close connections, etc.).

async function safeFetch() { try { const data = await riskyAPI(); console.log("✅", data); } catch (err) { console.error("❌", err.message); } finally { console.log("🏁 Cleanup"); } }

⏱️ Sequential vs Parallel Performance

Sequential (one-by-one): total time = sum of all tasks. Parallel (Promise.all): total time = slowest task. See the dramatic difference in real time!

// Sequential — 1 + 2 + 1.5 = 4.5s total await task(1s); await task(2s); await task(1.5s); // Parallel — max(1, 2, 1.5) = 2s total await Promise.all([ task(1s), task(2s), task(1.5s) ]);

🚀 Real-world Dashboard Combined

A realistic e-commerce dashboard using Promise.all + async/await to fetch orders, users, and inventory in parallel. Includes a flaky API with retry logic and try/catch error handling.

async function loadDashboard() { try { const [orders, users, stock] = await Promise.all([ fetchOrders(), fetchUsers(), fetchStock() ]); render({ orders, users, stock }); } catch (err) { showError(err); } }
